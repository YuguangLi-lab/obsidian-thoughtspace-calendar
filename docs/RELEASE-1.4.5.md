# 1.4.5 · Tasks 连续操作与任务界面

本地验证版本，已安装到专用测试库。沿用原有 Markdown 任务、日记与设置，无需迁移。本轮没有发布新的 GitHub Release。

## 连续操作与源文件保护

初轮 Tasks 审计确认并修复 11 类问题；一个问题可能包含多个失败断言，以下按行为统计。

| 问题 | 修复后的行为 |
| --- | --- |
| 同一任务排期、优先级、完成快速连改失败 | 核对本次写入后的完整结果，为仍属同一轮的后续操作重新定位 |
| 旧重复任务的属性动作改到新轮次 | 所有重复任务修改都校验轮次，阻止过期操作 |
| 完成、撤销后继续处理另一任务失败 | 撤销同步映射合法的独立任务行 |
| 旧撤销误删外部生成的同文重复任务 | 重复任务收据验证实际事务中的任务快照 |
| 写入尚未结束时到达的点击漏映射 | 写后核对通过后，再处理当前已排队的合法操作 |
| 手动象限标记阻断 Tasks 规则解析 | 将自己的隐藏标记放在说明与元数据之间，兼容旧尾部标记及重开 |
| 嵌套重复任务被验证器当作代码 | 仅校验阶段去除列表外层上下文，落盘保留缩进和引用前缀 |
| 新生成同文任务抢走原任务焦点 | 使用插件实例内的临时身份，只沿已验证的行映射转移 |
| 时间线忽略搜索和标签 | 对当天任务和随记应用筛选，冲突仍根据完整当天日程判断 |
| 四象限刷新回到列顶部 | 连续修改保留各列滚动；切换范围或搜索时允许重置 |
| 普通任务新增重复规则后，旧撤销改掉外部新轮次 | 结果任务新增规则时也记录轮次保护 |

另修复删除最后一个筛选标签后的摘要残留，合并该场景的时间线重绘。写入失败不会阻断后续正常操作；块引用、CRLF、Tasks 配置差异及 Dataview 格式仍纳入回归。

## 界面与操作

新增统一的日历与日记视觉：月历保留柔和渐变，日期、导航与工具图标对齐；日记采用清晰日期标题、原生 Markdown 正文和轻分隔，周月清单突出日期与摘要。正文继承 Obsidian 字体和字号。

任务标题与标签、重复规则分开显示，来源放在页脚；保护链接、代码与转义中的文字，展示整理不改写原文。大日历在密集日期最多预览三项日程与任务，保留完整待办数量和更多入口，避免内容跨格。

时间线的轨道和节点更紧凑，时间、正文、来源分层呈现；未定时任务单独折叠。列表的更多、顺延操作常驻显示，避免反复悬停寻找入口。正文继续使用 Obsidian 字体，深浅色主题和 280px 窄侧栏均通过布局检查；四象限保持 2×2。

搜索中的隐藏任务仍参与冲突判断；筛选时不推断可安排空档，避免把隐藏任务占用的时间当成空闲时间。当前时间计时器保留卡片和焦点。

## 拖选时间与时间线排期

周视图空白区域按住拖动，实时显示起止时间；支持反向选择，按 15 分钟吸附。松开打开预填日程窗口，单击仍保持原有一小时默认时长，保存前不会写入苹果日历。

任务列表、四象限、时间线及大日历的任务安排窗口加入 24 小时时间条，可拖选范围、拉动结束手柄延长时间。手动输入保留精确分钟；手柄方向键调整 15 分钟，Shift 配合方向键调整 1 分钟。侧栏时间线支持拖动定时与未定时任务，落点显示目标时间，并可跨视图拖到大日历；保留原有效时长，未定时默认 30 分钟。

原生测试定位并修复活动拖选与 Obsidian Modal Escape 的冲突，使用公共 Keymap Scope 仅在手势期间接管 Escape；取消后正常恢复关闭行为。时间条宽度或周列高度在手势中变为零时取消，不提交或误开窗口。保存期间锁定控件，拖动期间延后重绘。

长任务中大量未配对方括号的展示解析改为一次索引扫描，避免重复扫描；展示处理仍不改写 Markdown。

## 10 月 12 日追加：拖动稳定性与预览

本轮追加确认并修复 21 类问题：周视图 12 类、时间控件与时间线 7 类、视觉边界 2 类。每类可能对应多个断言；统计不含上一轮修复。

周视图调整时长改用实时列坐标，滚动或侧栏缩放后仍对应正确时间；松手采用最后位置。非活动触点、轻微抖动、失去指针捕获、关闭视图及零尺寸列均有独立处理，取消会恢复原时长和提示。没有实际移动时保留手动输入的精确分钟。

保存期间保持编辑锁，直到新任务正文或日程版本重新加载到网格；旧卡片不能在这个窗口再次打开排期或编辑。时间线将拖动结束、索引通知和保存完成合并为一次正文重绘，连续拖动保留当前行与滚动位置。保存失败的错误提示保持可见，可在同一窗口重试；重复提交只执行一次写入。

时间条起止手柄分离，时间与时长摘要更清晰。周网格选区保持真实时长，时间标签独立浮动，短时段和接近日末的预览可完整阅读。调整时长显示范围提示；深浅色与窄侧栏继续使用 Obsidian 原生字体和控件。

跨窗口移动时间控件后，监听绑定到新的所属窗口；移动中的手势取消并释放临时 Escape Scope。方向键仅通知实际变化的时间字段，无变化的边界操作不触发刷新。另修复精确午夜结束的日程切换为全天时多占下一天的问题。

## 使用与边界

完整本地安装包为 `release/thoughtspace-calendar-1.4.5.zip`。升级保留 `data.json` 和笔记；需要苹果日历时保留完整原生桥接程序。重复任务需要 Tasks 7.2+，本轮实测 8.5.0。

源文件中的外部任务变化可能使重复任务的撤销被保守拒绝，此时请打开原文检查；不猜测目标轮次。独立正文修改在任务行未变化时仍可保留并撤销。

本轮未读写真实苹果日程。短时连续操作检查不能证明长期无泄漏或所有大库场景性能；移动端及 Windows/Linux 原生界面未在本轮验证。
