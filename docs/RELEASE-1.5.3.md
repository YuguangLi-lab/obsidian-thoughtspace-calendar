# 1.5.3 · 计时统一进入日历

完整计时器并入日历，告别重复的侧栏页面。日历与计时通过顶部按钮切换，下方待办继续可用。

在日历顶部切换「日历 / 计时」，即可使用正计时、倒计时、番茄钟、预设与自定时长、计时记录等完整功能。独立计时侧栏入口已移除。

任务、时间线、大日历、状态栏及原有快捷命令都回到同一个日历计时页。旧版工作区里的独立计时页面会自动合并；已有日历的日期和任务筛选状态保留。

计时使用现有会话和存储，页面迁移不改变计时状态。升级时保留 `data.json` 与 `pomodoro-state.json`，不要覆盖个人笔记。

旧页面迁移会识别尚未加载的日历，避免重复页面；迁移期间切回笔记仍保留原焦点。记录中的日历入口继续打开大日历，查看对应日期的实际投入。

## 连续操作与界面

任务或日记刷新时保留计时控件，不重新订阅控制器；未提交的事项名称、自定时长、光标位置和焦点继续保留。切换页面不重置会话，不自动完成任务或创建苹果日程。界面跟随 Obsidian 字体与主题，检查覆盖浅色/深色和 230、280、420 像素宽度。

## 安装与升级

从 [1.5.3 Release](https://github.com/YuguangLi-lab/obsidian-thoughtspace-calendar/releases/tag/v1.5.3) 下载完整 ZIP，将 `main.js`、`styles.css`、`manifest.json` 和整个 `native/` 放到 `.obsidian/plugins/thoughtspace-calendar/` 后重载插件。保留 `data.json`、`pomodoro-state.json` 和个人笔记；不要用整个插件目录覆盖方式删除原设置。旧计时页会自动合并，无需手动迁移记录。

## 验证

467 项单元测试、21 项日历内计时浏览器检查、65 项大日历浏览器检查、29 项官方 Tasks API 契约检查通过。18 项真实测试库页面和数据检查确认唯一日历、连续打开/切换/刷新、计时状态与记录保留；101 篇原笔记 SHA256 未变。

原生检查保留现有暂停会话，没有启动或结束用户计时，也未修改苹果日程。真实系统授权、云同步和长期内存表现不由这些检查代替。完整证据和边界见 [本版验证报告](../qa/RELEASE-VERIFY-1.5.3.json)。
