# ThoughtSpace 日历与日记 1.4.1

本次集中完善 Tasks 重复任务联动。

此前，Tasks 的全局过滤器未匹配时，官方 API 可能仅返回一条勾选完成的任务。本版在写回前验证下一次重复任务确已生成，避免漏项；失败时保留原文，并提示检查重复规则、过滤器和任务格式。

同时支持 Dataview 方括号、圆括号的重复与日期属性，保留排期写回格式，让下一次任务按正确日期进入日历。多行撤销、重复点击防重、重新打开完成项和块引用保护继续生效。

需要启用 Tasks 7.2 或更新版本，重复规则与任务格式遵循 Tasks 设置。自定义复选状态、完成后删除等仍请在原文操作。本版没有安装或修改 Tasks 插件，也没有修改苹果日历配置。

[功能说明](../FEATURES-1.4.1.md) · [使用指南](USAGE.md#tasks-重复任务) · [验证记录](../qa/RELEASE-VERIFY-1.4.1.json)

安装包以 [GitHub Releases](https://github.com/YuguangLi-lab/obsidian-thoughtspace-calendar/releases) 实际发布为准，本文不表示已上传。

单行完成结果也可能表示重复规则已经结束。公开 API 不返回结束原因，无法可靠区分它与普通勾选回退，因此这种情况会保留原文并提示在源笔记中完成。
