# 苹果日历联动

## 支持范围

桥接使用 Apple EventKit，包含 Apple Silicon 和 Intel 通用二进制，最低 macOS 14。其他桌面系统不能调用该原生接口。

日程保存在系统日历账户中，插件处理所选日历的查询和修改。不需要填写 iCloud 密码，不直接读写 Calendar 数据库；账户的联网与云同步由 macOS Calendar 负责。

**本轮没有对真实苹果日程执行写入测试。** 输入校验与合成/内存夹具交互不能代替真实授权、真实读写往返和账户同步验证，苹果联动仍为实验功能。

## 连接步骤

1. 安装完整 ZIP，保留 `native/ThoughtSpaceCalendarBridge.app`。
2. 在大日历右上角打开连接设置，或执行“苹果日历连接与选择”。
3. 点击“连接苹果日历”，在系统提示中允许完整读写权限。
4. 选择显示日历及默认可写日历，保存。
5. 返回大日历刷新，检查日期范围；新建或修改时确认目标日历。

插件加载时不请求权限；只有主动连接才会请求。显示选择为空时不读取任何日历。断开连接停止后续查询，系统权限仍由 macOS 设置管理。

## 创建和编辑

支持标题、开始/结束时间、全天、目标日历、地点、备注。点击周视图空白格可预填时间；打开编辑窗口时载入完整备注。

只读日历只能查看。重复日程的修改针对当前场次，不编辑整套规则。全天结束日期在界面中表示包含的最后一天，系统采用下一天零点作为排他结束。

保存前检查版本，发生冲突时保留编辑草稿。保存期间按钮和字段锁定，结果不明时不自动重试；请先在苹果日历确认，避免重复创建。

## 拖动和调整时长

| 操作 | 结果 |
| --- | --- |
| 拖到月格或另一日期 | 更改日期，保留原来的开始时间和时长 |
| 定时日程拖到周时间格 | 更改开始时间，按 15 分钟吸附，保留时长 |
| 拖动周时间块底部手柄 | 修改结束时间，按 15 分钟吸附 |
| 全天日程拖到日期/全天区域 | 保留全天性质及自然日跨度 |
| 跨日事件 | 仅起始日片段可拖动改期，末日片段可调整结束 |
| 只读日程 | 可以打开详情，不能拖动或缩放 |

需要精确时间时打开编辑窗口输入。全天日程不能直接拖进小时格转为定时日程。修改前会再次读取完整日程并检查版本，避免从列表摘要保存时丢失备注。取消拖动或缩放不提交修改。

拖动保存失败会重新读取并展示实际数据；遇到版本冲突请刷新后重新操作。无法确认保存结果时不会自动再提交。

## 与笔记、任务联动

大日历右侧时间线合并展示定时 Markdown 任务和苹果日程，全天事项另列。Markdown 任务只写回自己的笔记，排期不会自动生成苹果事件。

日程条目下可新建关联笔记，或通过原生搜索关联已有笔记。关系保存在本地 Markdown 的 `thoughtspace-calendar-events` 文本列表属性，不向苹果上传笔记正文或仓库路径。原生改名、移动笔记后，入口仍指向最新路径。

插件内改期后会更新必要的关联标识；若系统日程已经保存而本地关联更新失败，会明确提示重新关联已有笔记，不重复提交日程。重复日程按场次关联，在插件外调整场次后可能需要重新选择关联笔记。新笔记的日期/时间属性是创建时快照，后续修改不会重写正文。

## 刷新方式

外部修改在手动刷新、窗口回到前台或可见页面定时刷新时更新，不是系统事件推送。可见页定时刷新约每 60 秒触发；查询缓存 TTL 为 45 秒，最多保留 12 个范围。拖动、调整时长和保存期间推迟刷新，减少操作中断。

单次查询不超过 62 天，最多 2,000 个事件。达到上限会提示缩小范围；月格和当日详情控制单次渲染数量。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 接口未响应 | 检查完整 `native/`、应用包结构、可执行权限和 macOS 14+ |
| 没有显示日程 | 确认已授权、已勾选日历、日期范围正确，然后刷新 |
| 系统拒绝授权 | 到 macOS 系统设置 → 隐私与安全性 → 日历检查权限，再重新连接 |
| 只能看不能编辑 | 日历可能只读；跨日事件的中间片段也不能拖动改期 |
| 保存冲突 | 编辑窗口保留草稿；刷新确认最新事件后重新修改 |
| 保存结果不确定 | 先在苹果日历确认是否已写入，不要直接重复创建 |
| 找不到原关联笔记 | 用链接图标重新选择；确认笔记属性未被删除 |
| 更新后连接不可用 | 确认完整桥接包已更新，而非只替换三个根目录文件 |

桥接包为本地 ad-hoc 签名，未做 Apple Developer ID 公证。系统可能依据下载来源和安全策略限制执行；本项目不清除系统隔离属性来绕过限制。开发者可审阅 Swift 源码并自行构建。

## 尚未提供
