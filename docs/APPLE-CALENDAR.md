# 苹果日历联动

## 支持范围

桥接使用 Apple EventKit，包含 Apple Silicon 和 Intel 通用二进制，最低 macOS 14。其他桌面系统仍可使用核心日历与任务，但不能调用该原生接口。

日程数据保存在系统日历账户中，插件只处理所选日历的查询和修改。没有 iCloud 密码配置，不直接读写 Calendar 数据库。账户的联网与云端同步由 macOS Calendar 负责。

**1.3.0 的真实授权与真实日程读写往返还未完成验证。** 已验证原生接口输入检查、状态查询、构建包、隔离编辑交互和原生 Obsidian 中的内存夹具编辑。

## 连接步骤

1. 安装完整 ZIP，保留 `native/ThoughtSpaceCalendarBridge.app`。
2. 在大日历右上角打开连接设置，或执行“苹果日历连接与选择”。
3. 点击“连接苹果日历”，根据系统提示允许完整日历读写权限。
4. 选择需要显示的日历，以及默认可写日历，保存。
5. 返回大日历刷新，检查显示范围；新建或修改日程时确认目标日历。

插件加载时不请求权限；只有主动连接才会请求。显示选择为空时不读取任何日历。断开插件连接停止后续查询，但不会替你撤销系统权限。

## 创建和编辑

支持标题、开始/结束时间、全天、目标日历、地点、备注。点击周视图空白格会预填时间。列表查询不保存完整备注缓存；打开编辑窗口后再载入完整备注。

只读日历只能查看。重复日程的修改针对当前场次，保留原场次定位，不会编辑整套重复规则。全天结束日期在界面中表示包含的最后一天，系统使用下一天零点作为排他结束值。

保存前比较日程版本。如果事件已在其他位置修改，保留当前草稿并提示重新载入。保存期间按钮与字段锁定，避免重复提交。结果不明确时不会自动重试；先到苹果日历确认再继续操作。

## 刷新方式

外部修改在手动刷新、窗口回到前台或可见页面定时刷新时更新。可见页的定时刷新约每 60 秒触发；不是系统事件推送。查询缓存 TTL 为 45 秒，最多保留 12 个范围。

单次查询不超过 62 天，最多 2,000 个事件。达到上限会提示缩小范围；月格不直接渲染全部日程。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 接口未响应 | 检查完整 `native/` 目录、应用包结构和可执行权限；确认 macOS 14+ |
| 没有显示任何日程 | 确认已授权、已勾选显示日历、日期范围正确，然后刷新 |
| 系统拒绝授权 | 到 macOS 系统设置 → 隐私与安全性 → 日历检查相关权限，再重新连接 |
| 只能看不能编辑 | 当前日历可能是订阅或只读日历；选择可写日历创建 |
| 保存冲突 | 草稿保留；复制所需文本，刷新确认最新事件后重新编辑 |
| 保存结果不确定 | 先在苹果日历确认是否已经写入，避免再次创建重复日程 |
| 更新后连接不可用 | 确认完整桥接包已更新，而不是只替换三个根目录文件 |

桥接包为本地 ad-hoc 签名，**没有 Apple Developer ID 公证**。系统可能依据下载来源和安全策略限制执行；本项目不通过清除系统隔离属性来绕过限制。开发者可审阅 Swift 源码并按开发指南自行构建。

## 尚未提供
