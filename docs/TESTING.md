# 历史基线：1.4.2 验证范围

## 本地验证

2026-10-11，本版通过 270 项自动化测试、19 项官方 Tasks API 检查、30 项浏览器交互检查、36 项 Tasks 原生联动检查和 36 项通用原生工作流检查。新增回归检查包括无日期重复任务的外部写入冲突、重复通知合并、无变化扫描、读取失败恢复与文件移动/删除。检查结果、构建信息与运行文件 SHA256 见 [1.4.2 报告](../qa/RELEASE-VERIFY-1.4.2.json)。个人仓库路径、安装日志和工作区快照不公开。

### 安装 Tasks 后的原生检查

本轮在专门测试库安装并启用官方 Tasks 8.5.0。通过实际 Obsidian 任务控件操作，检查列表、四象限、时间线和大日历；对照原文与 Tasks 索引验证下一次任务、完成日期、块引用及撤销。另覆盖重复点击、Tasks 刚写回时日历仍显示旧条目的竞争场景、Dataview 格式和 Tasks 设置差异。36 项检查均通过：一次勾选的索引通知从 2 次减为 1 次，列表重绘从 2 次减为 1 次，无变化扫描不再通知刷新，勾选后的焦点恢复正常。

测试前后，101 篇原有笔记的 SHA256 一致。临时测试笔记已清理，Tasks 配置恢复到安装后的初始状态；官方 Tasks 插件保留安装并启用。

测试使用唯一命名的夹具笔记。脚本会临时调整 Tasks 配置以覆盖不同设置，在结束时恢复原配置、工作区布局和撤销状态，并删除夹具；测试期间阻止苹果日历读取。只在专门测试库、两个插件均已启用时运行：

```sh
python3 qa/native-tasks-check.py --vault 测试仓库名称
```

该脚本不安装插件。安装记录与原生检查结果属于本轮证据，不能用较早的隔离 API 检查替代。

### 其他回归检查

原有场景继续覆盖任务拖动排期、精确分钟、跨午夜时长、取消、外部修改冲突、写回和撤销、笔记关联与改名。可运行 `python3 qa/native-workflow-check.py --vault 测试仓库名称` 检查这些交互；脚本同样使用独立夹具并恢复布局。本轮 Tasks 已启用，因此跳过 5 项仅在未安装 Tasks 时执行的保护检查，其余 36 项通过；不将跳过项计入本轮通过数量。

隔离 API 检查使用未经修改的官方 Tasks 8.5.0 发布代码，在 VM 中调用真实公开 API，再由本地桥接验证结果，覆盖每日、工作日、完成后重复、字段格式、生成顺序、块引用、完成日期关闭、重开、无效规则和全局过滤器回退。先从 [Tasks 8.5.0 官方发布页](https://github.com/obsidian-tasks-group/obsidian-tasks/releases/tag/8.5.0) 获取 `main.js`，再运行：
