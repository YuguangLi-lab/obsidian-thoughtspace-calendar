# 1.3.0 验证范围

## 本地验证

原开发版本在 2026-10-01 完成以下检查：176 项自动化测试、15 项隔离 Chrome 交互检查、20 项原生 Obsidian 检查。具体检查名称与运行文件 SHA256 保留在 [公开报告](../qa/RELEASE-VERIFY-1.3.0.json)。个人仓库路径、安装日志和工作区快照不公开。

自动化包括原生接口的 `validate` / `validate_range` 调用，不请求日历权限。原生 Obsidian 中的日程编辑使用临时内存夹具。仅状态查询访问原生程序，未读取或写入真实日程。

## GitHub 发布验证

新仓库从干净目录重新安装依赖、执行构建和自动化测试，再运行隔离浏览器交互检查。GitHub Actions 使用 macOS 跑同一套检查；CI 状态请以仓库 Actions 页面为准。

完整发布包会重新解压检查路径、运行文件 SHA256、应用包代码签名、二进制架构和可执行权限。

## 不能从这些结果推断的结论

- 系统权限弹窗和真实日历创建/编辑已通过。
- 云端账户在各种网络条件下已通过双向同步。
- 插件在 Windows/Linux 与全部主题上兼容。
- 长期运行不会泄漏内存，或任意规模仓库都有相同速度。

上述项目尚待专门验证。苹果联动在文档中标记为实验功能。
