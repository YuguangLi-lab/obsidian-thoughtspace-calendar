# 使用指南

## 三个页面如何配合

- **大日历**在主工作区查看月/周安排，右侧是选中日期的日程与任务。
- **日历与任务**在右侧边栏展示紧凑月历以及任务列表、四象限或时间线。
- **日记与清单**是独立侧栏页面，用来阅读日记、查看周期清单和当天新建笔记。

日历浏览不会为每个日期自动创建日记。点击“打开日记”或进入相应记录时创建或复用文件。编辑日记会打开 Obsidian 原生 Markdown 页面。

## 任务语法

普通复选框就是任务：

```markdown
- [ ] 整理资料
- [ ] 09:00 - 10:00 写作 ⏳ 2026-10-01 ⏫ #工作 ^draft-task
- [ ] 交付草稿 📅 2026-10-03
- [x] 完成检查 ✅ 2026-10-01
```

| 标记 | 含义 |
| --- | --- |
| `⏳ YYYY-MM-DD` | 计划日期 |
| `📅 YYYY-MM-DD` | 截止日期 |
| `✅ YYYY-MM-DD` | 完成日期 |
| `🔺 ⏫ 🔼` | 最高、高、中优先级 |
| 无优先级符号 | 普通 |
| `🔽 ⏬` | 低、最低优先级 |
| `09:00` / `09:00 - 10:00` | 当日开始时间 / 时间段 |
| `#工作` | 标签筛选 |
| `^draft-task` | 原有 Obsidian 块引用，安排和分类时保留 |

当天任务来自计划/截止日期为当天的任务，或位于该日日记中且未另行安排日期的任务。当天已完成优先使用完成日期；没有完成日期的旧任务按其归属日期判断。

时间范围需要结束时间晚于开始时间；跨日任务拆到相应日期。日期或时间写在代码片段、代码围栏和隐藏注释中时不作为安排。

## 三种任务模式

### 列表

通过任务区的列表图标切换。更多筛选包含日期范围、关键词、标签、排序和分组。任务旁的来源入口会打开原始笔记；安排入口可以同时设置计划日期、截止日期、时间和优先级。

### 四象限

通过四格图标切换，布局固定为 2×2。自动分类以选中的日期为基准：最高/高优先级视为重要，截止日期已到视为紧急。拖动到另一象限时写入显式分类，不擅自改变优先级和日期。

手动分类保存为任务行中的 `<!-- thoughtspace:quadrant=q1 -->` 等隐藏标记。通过菜单恢复自动分类可移除该标记。拖动期间可按 Escape 取消；搜索和标签筛选仍然有效。

### 时间线

通过时钟图标切换，查看有具体时间的当日任务和日记时间记录。可以显示当前时间、未安排事项、空档和冲突。Markdown 任务与苹果日程是独立数据：给任务安排时间不会自动创建苹果日程。

含 `🔁` 的重复任务不会在本插件内完成，以免损坏第三方 Tasks 插件的规则。

## 日记和周期记录

- 点击日历日期进入日记。
- 周编号、月份、季度和年份入口打开相应周期笔记。
- 新日记位于设置的根目录下，按年/月存储；已有根目录日期日记优先复用。
- “关联当天新建笔记”开启后，将笔记链接写入日记的受管理区域，不复制正文。文件创建时间受同步/导入方式影响，可能不同于你的实际写作时间。
- “收集笔记”会创建普通 Markdown 文件并打开原文，目录可设置。

## 在 Markdown 内嵌任务面板

在日记或任意笔记中加入：

````markdown
```thoughtspace-tasks
2026-10-01
```
````

面板通过共享任务索引显示该日相关的任务，支持筛选与操作。日期格式需要有效的 `YYYY-MM-DD`。

## 更新建议

手动更新前保留 `data.json`；使用发布包替换运行文件和完整 `native/`。已有日记不会因更新而自动改名。需要整理旧日记时，从设置主动执行归档；该操作先备份，跳过同名目标。
