# 使用指南

## 三个页面如何配合

- **大日历**在主工作区查看月/周安排，右侧是选中日期的统一时间线、任务和关联笔记入口。
- **日历与任务**在右侧边栏展示紧凑月历以及任务列表、四象限或时间线。
- **日记与清单**是独立侧栏页面，用来阅读日记、查看周期清单和当天新建笔记。

浏览日期不会自动为每一天创建日记。点击“打开日记”或进入相应记录时创建或复用文件。编辑使用 Obsidian 原生 Markdown 页面。

## 从任务安排一天

1. 在任务列表或四象限找到未完成任务，拖动标题或手柄到大日历的日期格。
2. 切到周视图，将任务拖到目标时间；指针附近显示落点时间，按 15 分钟吸附。
3. 拖动时间块底部手柄调整结束，或点任务旁的时钟打开“安排任务”，按分钟精确输入。
4. 大日历右侧的“时间线”会把定时任务与苹果日程按开始时间放在一起。点击任务标题回到原文，点击复选图标完成任务。

月格拖动只改计划日并保留时间；拖入周网格保留原有有效时长，否则默认 30 分钟。只填写日期时保留原时间，清除时间可使用任务列表原有安排入口。开始和结束必须位于同一天，结束晚于开始，最晚到 23:59。

计划日期和截止日期不同的任务会在两天出现，截止日条目是提醒；请拖动计划日的时间块安排工作。已完成任务不能拖动。按钮、复选框、下拉框仍执行各自操作，不作为拖动手柄。

未写日期的任务在右侧“待安排”中集中显示，展开后可以拖入日期或点击时钟安排。它不会把无日期任务当作今日任务。

## 拖动选择时间

- **新建日程**：在大日历周视图空白处按住拖动，选择开始与结束。松开会打开预填窗口，确认保存后才创建苹果日程；单击仍默认一小时。需要启用苹果日历连接。
- **安排任务**：在列表、四象限或时间线点击安排入口，在时间条上拖选时段。拉动左右手柄修改边界，结束手柄向右拉可延长时长。点击保存后写回原任务。
- **精确调整**：拖动按 15 分钟吸附，手动输入可精确到分钟；选中手柄后方向键调整 15 分钟，Shift＋方向键调整 1 分钟。
- **取消手势**：拖选中按 Escape 保留原输入；非拖选状态按 Escape 正常关闭窗口。失焦、取消触摸或关闭窗口均不提交预览。
- **连续调整**：保存到新网格加载完成前暂时锁定编辑，完成后可继续拖动。保存失败保留错误提示和输入，可直接重试。
- **查看范围**：短时段的预览标签与选区分开显示；选区高度对应真实时长，标签不受日末边缘裁切。

所有时段位于同一天，最晚到 23:59。任务保存仍保留重复规则、截止日期和块引用，可用撤销回退。

## 任务语法

普通复选框就是任务：

```markdown
- [ ] 整理资料
- [ ] 09:00 - 10:00 写作 ⏳ 2026-10-11 ⏫ #工作 ^draft-task
- [ ] 交付草稿 📅 2026-10-13
- [x] 完成检查 ✅ 2026-10-11
```

| 标记 | 含义 |
| --- | --- |
| `⏳ YYYY-MM-DD` | 计划日期 |
| `📅 YYYY-MM-DD` | 截止日期 |
| `✅ YYYY-MM-DD` | 完成日期 |
| `🔺 ⏫ 🔼` | 最高、高、中优先级 |
| 无优先级符号 | 普通 |
| `🔽 ⏬` | 低、最低优先级 |
| `09:00` / `09:00 - 10:00` | 当日开始时间 / 时间段 |
| `#工作` | 标签筛选 |
| `^draft-task` | 原有 Obsidian 块引用，安排和分类时保留 |

当天任务来自计划/截止日期为当天的任务，或位于该日日记中且未另行安排日期的任务。当天已完成优先使用完成日期；没有完成日期的旧任务按其归属日期判断。代码片段、代码围栏和隐藏注释中的日期、时间及任务示例不会作为实际安排。

## 三种任务模式

### 列表

点击列表图标。更多筛选包含日期范围、关键词、标签、排序和分组。来源入口打开原始笔记；安排入口可以设置计划日期、截止日期、时间和优先级。未完成任务可直接拖到大日历。

### 四象限

点击四格图标，布局固定为 2×2。自动分类以选中的日期为基准：最高/高优先级视为重要，截止日期已到视为紧急。拖到另一象限只修改显式分类，不擅自改变优先级和日期；拖到大日历则安排日期和时间。

手动分类保存为任务行中的 `<!-- thoughtspace:quadrant=q1 -->` 等隐藏标记。通过菜单恢复自动分类可移除标记。拖动期间可按 Escape 取消；搜索和标签筛选仍然有效。

### 时间线

侧栏的时钟图标展示定时任务和日记时间记录，保留当前时间、未定时事项、空档和冲突提示。大日历右侧另外提供**任务与苹果日程合并的时间线**，并分别收纳全天日程、当日待办、已完成和待安排事项。

侧栏时间线的任务可拖到其他定时事项或空档，落点预览目标时间；也可拖到大日历。保留原有效时长，未定时任务默认 30 分钟。日记时间记录可以作为落点参考，其正文不会被拖动改写。

给任务安排时间只修改原笔记，不会自动创建苹果日程。

时间线卡片顶部的时间是可点击入口：修改计划日期、截止日期、开始／结束时间及优先级后，点击“保存安排”。输入分钟不会被拖动的 15 分钟吸附规则取整。卡片底部的来源名称可打开原笔记；旁边的调整图标也可进入编辑器。

1.4.4 的分钟刷新只更新当前时间与进行中标记，不重建卡片。时间安排本身或任务状态改变时，才更新对应任务视图。

### Tasks 重复任务

安装并启用 Tasks **7.2 或更新版本**后，本插件检测其 [官方 API](https://github.com/obsidian-tasks-group/obsidian-tasks/blob/main/docs/Advanced/Tasks%20Api.md)。含 `🔁`、`[repeat:: …]` 或 `(repeat:: …)` 的重复任务可在列表、四象限、时间线及大日历中直接勾选，由 Tasks 处理后续任务、完成日期和顺序。

请使用与 **Tasks 设置中的任务格式**一致的语法。例如默认的 Tasks 格式：

```markdown
- [ ] 每日阅读 #task 🔁 every day 📅 2026-10-11
- [ ] 工作日复盘 #task 🔁 every weekday ⏳ 2026-10-12
```

若 Tasks 选择了 Dataview 格式，则可以写：

```markdown
- [ ] 每日阅读 #task [repeat:: every day] [due:: 2026-10-11]
```

`#task` 只是示例：如果设置了 Tasks 全局过滤器，任务必须包含你配置的过滤文本。插件会检查 Tasks 是否实际生成下一次任务；没有生成时，保留原文并提示检查重复规则、过滤器和格式，避免任务被直接勾完却没有后续。

Dataview 的 `due`、`scheduled`、`completion` 和 `priority` 字段会用于日历日期、完成筛选和排序；修改排期、优先级时保留对应格式。完成后的下一次任务重新索引到其日期，不复制整篇笔记。重新打开已完成任务只重新打开当前项；若要回退整次完成及生成操作，请使用撤销。

**连续操作（1.4.5）**：支持同一任务先改时间、优先级再完成，也支持连续完成不同任务、撤销后继续处理其他任务。只有完整写入结果核对通过的合法排队操作会重新定位。新的重复轮次拥有独立的临时焦点身份；外部原文变化后请刷新确认。对重复任务的撤销会校验同篇笔记的任务快照，避免误改外部生成的新轮次；不影响任务行保持一致的独立正文编辑。

**象限与筛选**：手动调整象限保留重复规则；旧尾部标记会在 Tasks 操作时兼容处理。时间线支持“更多筛选”中的搜索和标签，仍按完整当天安排判断冲突。筛选期间不提示可安排空档。

没有兼容 API 时，重复任务复选框保持禁用。普通任务继续原有完成逻辑。自定义复选状态、完成后删除等暂不支持的 API 输出会停止写入并提示打开原文，不会尝试猜测或改写其行为。

撤销重复任务操作时，会检查被替换的完整任务区间；若这些行已被其他编辑修改，请到原文确认。其他正文编辑不会被回滚。

## 日程与笔记

在大日历右侧的日程条目下：

- 点击 **新建关联笔记**，在收集笔记目录的“日程”子目录创建并打开 Markdown。
- 点击 **关联已有笔记**图标，在 Obsidian 原生搜索框中选择笔记。
- 已关联时显示笔记名称，点击在原生编辑器中打开。

关系使用 `thoughtspace-calendar-events` 文本列表属性，随笔记保存，可在 Obsidian 属性和 Bases 中查看。删除相应属性值可解除本地关系；不会删除笔记或苹果日程。笔记移动、改名后仍会更新入口。

新建笔记中的日期/时间是创建时快照；修改日程不会自动改写笔记正文。关联操作不向苹果上传笔记正文或仓库路径。重复苹果日程按场次关联，在插件外调整场次后如找不到原关联，可重新选择已有笔记。

日程拖动、系统权限及冲突处理见 [苹果日历指南](APPLE-CALENDAR.md)。

## 日记和周期记录

- 点击日历日期进入日记；周编号、月份、季度和年份入口打开相应周期笔记。
- 新日记位于设置的根目录下，按年/月存储；已有根目录日期日记优先复用。
- 开启“关联当天新建笔记”后，链接写入日记的受管理区域，不复制正文。文件创建时间受同步/导入方式影响，可能不同于实际写作时间。
- “收集笔记”创建普通 Markdown 文件并打开原文，目录可设置。

## 在 Markdown 内嵌任务面板

在日记或任意笔记中加入：

````markdown
```thoughtspace-tasks
2026-10-11
```
````

面板复用同一个任务索引，支持筛选、操作及拖入大日历。日期需要有效的 `YYYY-MM-DD`。

## 更新建议

手动更新前保留 `data.json`；使用发布包替换运行文件和完整 `native/`。已有日记不会因更新自动改名。需要整理旧日记时，从设置主动执行归档；该操作先备份，跳过同名目标。可下载的版本以 [Releases](https://github.com/YuguangLi-lab/obsidian-thoughtspace-calendar/releases) 为准。

单行完成结果也可能表示重复规则已经结束。公开 API 不返回结束原因，无法可靠区分它与普通勾选回退，因此这种情况会保留原文并提示在源笔记中完成。

## 计时器与大日历

打开日历，在顶部切换到「计时」；也可从待办、时间线、大日历、状态栏或命令“在日历中打开计时器”进入同一页。三个模式在空闲或结束后切换：

| 模式 | 使用方式 |
| --- | --- |
| 正计时 | 从零开始，适合没有预估时长的工作。点击“结束并记录”保存实际用时。 |
| 倒计时 | 选择 15 / 25 / 45 / 60 分钟或输入 1–1440 分钟；运行、暂停时可增减 5 分钟。 |
| 番茄钟 | 默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟，每 4 轮长休息；设置页调整下一轮时长。 |

从列表、四象限、时间线或大日历点击任务计时图标：完整的起止时间将成为倒计时长度，否则开启正计时。关联来源、计划日期和计划时长保存在会话快照中。计时图标不会改动任务原文、勾选状态或重复规则。已有会话运行或暂停时，先结束并记录，再开始另一项工作。

大日历当日日程中的计时图标可以为苹果日程开始本地计时。只读日程也可以计时，但计时记录保存在插件本地，不会创建或修改苹果日程。全天日程默认正计时。

在大日历中查看实际用时：

- 月视图：日期格中的计时标记显示当日累计投入。
- 周视图：以独立样式显示实际活动段，暂停时间留为空档。实际记录不能拖动或拉长；计划任务和日程继续保留排期功能。
- 当日详情：查看实际用时记录、模式及计划与实际的对照；点击入口返回计时器。
- 正在进行的计时在大日历显示状态；每秒只更新文本，状态转换才刷新实际时间块。

日历里的计时页可命名自由活动、打开关联笔记、查看对应日期和记录。按“暂停”停止累加，按“继续”恢复；“结束并记录”保存已投入时间。倒计时或番茄专注到零后只结束当前阶段，不会自动连续启动下一轮。

最近 200 条用时记录与当前会话保存在 `.obsidian/plugins/thoughtspace-calendar/pomodoro-state.json`。沿用文件名和视图 ID 兼容旧番茄钟。旧记录保留；旧运行会话恢复为番茄模式。请在更新时保留该文件与 `data.json`。Obsidian 关闭期间不会发出提醒，重新打开后根据截止时间或开始时间恢复。秒表单次活动累计最多 7 天，活动段最多 500 段；达到限制需结束当前计时。


## 共享番茄计时条与紧凑侧栏（1.5.1）

侧栏顶部通过“日历 / 计时”按钮切换，两个页面共用空间；下方待办保持原样。日记／周期清单顶部显示同一条计时状态。待机时点击播放开始番茄专注，运行时点击暂停，暂停时继续；点击更多计时操作，再点“结束并记录”保存实际用时。小计时条的展开入口回到日历里的计时页，仍控制同一会话。已有正计时或倒计时正在运行时，条内如实显示并控制当前模式。

日历顶部点击年月可打开月记／年记。更多日历工具提供跳转日期与月份、年历切换、季记和大日历；年份模式的前后按钮按一年切换。收集笔记仍为加号按钮。常用任务范围集中一组，更多筛选保留搜索、标签、排序与高级范围。日记正文保持原生 Markdown，编辑按钮继续打开原文。

## 日历与计时页切换

侧栏顶部的“日历 / 计时”共用同一区域。计时页包含完整的正计时、倒计时、番茄钟、预设和自定时长、活动名称、开始/暂停/继续、结束记录及历史。下方待办保持可用。日记与周期清单的小计时条控制同一个会话，其展开入口也回到日历，不再打开独立计时侧栏。

专注结束时，计时页预览下一阶段及预设时长；点击后才开始休息，休息结束后再开始专注。不因切换页面新建或覆盖正在运行的会话。

从 1.5.2 或更早版本升级后，已保存的独立计时页自动并入日历；已有日历的日期和任务视图保留。切换或刷新日历/任务时，未提交的计时事项名称和时长输入也会保留。
