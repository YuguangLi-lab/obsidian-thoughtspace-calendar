# ThoughtSpace 日历与日记 1.4.2

本次在测试库实际安装并启用 Tasks 8.5.0，修复重复任务更新冲突与任务视图的交互中断。

Tasks 从原文完成无日期重复任务后，新一轮任务可能与旧任务逐字相同。日历等待索引刷新期间，旧复选框现在会拒绝再次写入，避免误完成下一轮任务。

一次任务修改只发出一次索引通知；内容未变的扫描不触发重复重绘。列表勾选重绘后恢复键盘焦点，方便继续操作。

保留任务排期、Dataview 字段、块引用和检查原文后撤销的保护。重复任务需要 Tasks 7.2+；有限规则结束、自定义状态和完成后删除仍请在原文处理。本次不改变苹果日历的授权或同步配置。

验证通过 270 项自动化测试、19 项官方 API 检查、30 项浏览器交互检查、36 项 Tasks 原生联动检查及 36 项通用原生工作流检查。测试库的 101 篇原有笔记内容未变，夹具和临时设置已清理或恢复。
