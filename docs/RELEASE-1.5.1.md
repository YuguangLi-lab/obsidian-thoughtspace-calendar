# 1.5.1 紧凑月历、日记与共享番茄条（本地版本）

侧栏优先展示日期、当前事项和实际操作。年月与翻月集中到顶部；收集笔记保留快捷按钮，跳转日期、年历、季记和大日历收进“更多日历工具”。农历、节气、节日、休班标记、周编号和年月记录入口继续保留，窄侧栏只对工具行换行。

侧栏顶部增加“日历 / 计时”两个按钮，共用同一区域，默认显示月历；计时页隐藏月历，为下方待办释放空间。切换仅改变可见性，保留日期、筛选、待办 DOM 和正在进行的会话。日记与周期清单继续显示共享专注条。可开始番茄专注、暂停、继续，或展开完整计时器；结束操作先展开确认，再保存实际用时。正计时或倒计时正在进行时，计时条控制当前会话，不新建另一轮。完整计时器及大日历继续复用同一控制器，秒级更新只修改时钟和进度，不重建任务、月历或 Markdown 正文。

待办常用范围收紧为一组按钮与小计数，保留“更多筛选”。普通列表删除重复结果数与日期说明；搜索和标签筛选时显示匹配数与清除入口。空列表只显示一行提示，四象限保持 2×2 和各自的拖放入口。

日记日期、历史导航和编辑操作集中在头部，修正日期单位顺序。正文缩小标题间距并移除装饰横线，沿用原生 MarkdownRenderer、正文字体与编辑入口。只查看单日日记时只读取该日期的正文，周期清单仍读取相应范围。

设计来源与具体吸收点见 [布局参考](SIDEBAR-DESIGN.md)。本轮使用原生合成日记、实际计时器及浏览器窄侧栏进行验证，计时记录、设置、工作区和测试文件均恢复；精确结果见 [验证记录](../qa/RELEASE-VERIFY-1.5.1.json)。本版尚未发布 GitHub。
