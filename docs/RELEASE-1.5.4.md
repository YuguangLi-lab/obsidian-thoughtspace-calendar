# 1.5.4 · 计时页与农历排版

本版集中改进日历与计时的显示密度、视觉层级和窄侧栏布局。

完整计时仍在日历顶部的「计时」页。时间数字与小进度环分开，去除大圆环压住数字和多层边框的布局；阶段、事项输入、主要操作与辅助图标更紧凑。小时计时在窄侧栏中单独排一行，保留完整数字。

月历中的农历、节气和节日缩小为次要文字。正常侧栏为 9px，窄侧栏和紧凑模式为 8px；正常日期格由 44px 收紧至 40px。公历日期保持醒目，休班角标与日记标记分别预留空间。

界面继续使用 Obsidian 字体、主题与强调色。计时控制器、暂停和实际用时计算、记录存储、任务状态与苹果日程逻辑均沿用原实现。

467 项单元测试、92 项浏览器检查、29 项官方 Tasks API 契约检查与 22 项真实测试库检查通过。浏览器覆盖浅深色、230/280/420px、三种模式、小时计时与 125% UI 缩放；原生实测确认日期格收紧，连续开关与刷新保留 DOM。101 篇原笔记及原暂停计时状态、记录和设置未变。

验证范围见 [本版报告](../qa/RELEASE-VERIFY-1.5.4.json)。安装更新时保留 `data.json`、`pomodoro-state.json` 和个人笔记。

## 升级

从 [1.5.4 发布页](https://github.com/YuguangLi-lab/obsidian-thoughtspace-calendar/releases/tag/v1.5.4) 下载完整 `thoughtspace-calendar-1.5.4.zip`。关闭插件后，用其中的 `main.js`、`styles.css`、`manifest.json` 和 `native/` 更新插件目录，再重新启用。不要删除原有设置和计时数据文件。源码工程也可用安装脚本先备份再更新。
