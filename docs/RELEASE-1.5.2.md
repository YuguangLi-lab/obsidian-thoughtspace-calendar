# 1.5.2 专注计时面板

侧栏“计时”页从单行条升级为专注面板：大时钟、进度环、阶段与当前事项分别排列，主操作随准备、运行与暂停状态显示开始、暂停或继续。结束操作先确认，再保存实际用时；错误与重试留在当前界面。

日历与计时继续互斥显示；下方待办和筛选始终可用。日记与周期清单保留小型共享计时条，完整计时器及大日历继续复用同一控制器。计时刷新只更新时间与进度，不重建任务、正文或日历，也不触发苹果日历查询。

界面遵循 Obsidian 字体、主题和强调色，并适配窄侧栏与深色模式。合成示例见 [计时面板](images/sidebar-timer.png)。测试证据与范围见 [验证记录](../qa/RELEASE-VERIFY-1.5.2.json)。本版包含从 1.4.4 之后开发的完整改进，可直接升级，无需迁移笔记。

## 从 1.4.4 升级的主要变化

- 正计时、倒计时与番茄钟共用一个会话，可从任务或日程开始；暂停不计入实际用时。
- 大日历对照计划与实际投入，周视图保留暂停空档；跨日活动分段显示，休息不计为工作。
- 周视图拖选时间，任务时间条支持拖选及手柄调整，精确分钟输入继续可用。
- Tasks 连续修改、完成、撤销的轮次保护增强，保留块引用与嵌套结构，减少刷新造成的焦点和滚动中断。
- 月历与计时互切，日记头部及待办筛选收紧；四象限保持 2×2。

## 安装与升级

推荐从 [1.5.2 Release](https://github.com/YuguangLi-lab/obsidian-thoughtspace-calendar/releases/tag/v1.5.2) 下载完整 ZIP。解压后将 `main.js`、`styles.css`、`manifest.json` 和整个 `native/` 放到仓库的 `.obsidian/plugins/thoughtspace-calendar/`，随后重载插件。保留 `data.json`、`pomodoro-state.json` 和笔记；完整 ZIP 含苹果日历原生组件，仅替换三个运行文件不会补齐缺失组件。

关闭 Obsidian 后没有后台结束通知；计时记录不自动完成 Tasks 任务，不自动创建苹果日程。真实系统日历授权和云同步未由合成测试代替。
