# 1.5.0 通用计时器与日历联动（本地版本）

从任务或日程直接进入计时，再在大日历查看实际投入。侧栏提供正计时、倒计时和番茄钟：有完整时间范围的任务按计划时长倒计时，未定时任务正计时；自由活动可自行命名和选择时长。倒计时支持运行中增减 5 分钟，暂停期间不计入实际用时，“结束并记录”保存已经投入的时间。

计时界面改为紧凑的横向模式选择、数字时钟与小进度环。活动名称、计划范围、实际用时和主操作按使用顺序排列；暂停与结束并排，今日统计和最近记录更靠前。沿用 Obsidian 原生字体与主题，浅色、深色以及 230 / 280 / 360 像素侧栏均有布局检查。

大日历月格展示当日实际分钟；周网格将计划与实际活动段分别排列，暂停保留为空档；当日详情对照计划与实际，提供来源和计时器入口。实际记录为只读，避免与计划拖动、调整时长发生冲突。活动分段按本地日期裁剪，跨午夜不会把同一段完整计入两天；番茄休息不算工作投入。

底层继续使用单一插件计时器、绝对时间和原子保存。秒级刷新仅更新数字与进度，不重建任务、日历网格或查询苹果日历。切换任务前校验原文和当前轮次，运行或暂停中不能覆盖当前计时；保存失败保留现有状态。兼容旧番茄钟记录及命令，关闭侧栏与插件重载不丢失计时。

修复提前结束专注后重复进入长休息，以及旧暂停会话恢复后丢失估计标记的问题。旧记录无法还原准确暂停位置时，日历明确标为估计。近期记录上限 200 条，单个会话最多 500 个活动段。

本轮阅读了七个公开时间管理项目，具体吸收点见 [参考记录](TIMER-REFERENCES.md)。完整测试计数、原生恢复和原文保护结果见 [验证记录](../qa/RELEASE-VERIFY-1.5.0.json)。计时记录保存在本地，不自动完成 Tasks 任务或生成苹果日程；关闭 Obsidian 后没有后台结束通知。此次为本地版本，未发布 GitHub。
