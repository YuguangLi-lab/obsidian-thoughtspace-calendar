# 时间管理参考项目

本轮阅读以下项目公开的使用说明和功能设计，按 Obsidian 原生侧栏、既有 Tasks 索引与本地大日历实现。未复制第三方源码，也未新增这些项目的运行依赖。

| 项目 | 借鉴点 | 本轮落地 |
| --- | --- | --- |
| [Super Productivity](https://github.com/super-productivity/super-productivity) | 任务、日程、时间盒与实际用时结合；多种专注方式 | 计划任务与日程启动计时，实际投入对照计划；正计时、倒计时、番茄模式 |
| [Time Ruler](https://github.com/j-palindrome/obsidian-time-ruler) | Obsidian 任务和日历统一操作，正计时/倒计时，运行时增减时长 | 既有任务列表、四象限、时间线与大日历复用同一计时器；倒计时 ±5 分钟 |
| [Simple Time Tracker](https://github.com/Ellpeck/ObsidianSimpleTimeTracker) | 命名活动段，按开始/结束时间记录用时，时间戳恢复 | 活动名称、明确“结束并记录”、暂停分段、重载恢复和最近会话 |
| [Traggo](https://github.com/traggo/server) | 时间段在列表和日历中查看，本地可控数据 | 当日详情用时列表与周网格实际活动段、月视图累计分钟；不依赖远程服务 |
| [FullCalendar](https://github.com/fullcalendar/fullcalendar) | 月/周网格和拖动交互的清晰分工 | 保留现有计划拖动选时；实际记录独立、只读，防止排期手势与记录冲突 |
| [Obsidian Timer](https://github.com/Raboro/obsidian-timer-plugin) | 时长预设、开始/停止/恢复、状态栏 | 时长快捷选择、自由分钟输入、状态栏显示及清晰操作按钮 |
| [Workspace Clock](https://github.com/toya-co/obsidian-workspace-clock) | 原生 CSS 变量、命名会话和状态显示 | 延续 Obsidian 字体/主题，三模式紧凑侧栏、状态栏入口；作为补充参考 |

这里的“参考”指吸收操作与展现方式，未宣称完全复现各项目。未加入自动监控应用/空闲时间、远程账户或第三方后台服务。时间管理范围集中在用户主动开始的会话与现有任务/日历。
